# LibreMemo 디자인 비교 시안

`index.html`을 열면 아이콘 A–D와 화면 1–3을 자유롭게 조합하고, 서재·읽기 화면을 전환해 볼 수 있습니다. 플로팅 툴바의 색상 및 추가 도구 열기를 비교할 수 있습니다. 문서는 예시이며 파일 저장이나 사용자 데이터 처리를 수행하지 않습니다.

- A 페이지와 펜: 문서 저장과 주석의 의미를 직접 표현합니다.
- B H 모노그램: 작은 크기에서 브랜드를 선명하게 식별합니다.
- C 웹 북마크: 웹 페이지 보관의 의미를 강조합니다.
- D 열린 서재: 읽기와 개인 서재의 인상을 강조합니다.
- 1 포커스: 카드형 서재와 밝고 간결한 작업 화면입니다.
- 2 페이퍼: 목록형 서재와 종이색 읽기 화면입니다.
- 3 잉크: 다크 UI와 목차를 사용하며 문서는 밝게 유지합니다.

`icon-options.png`는 아이콘 비교표, `design-1.png`–`design-3.png`는 서재와 읽기 화면을 함께 그린 디자인 보드입니다. 실제 게시된 앱의 스크린샷이 아닙니다. `icons/`에는 직접 제작한 SVG 4종 및 192·512px PNG가 있습니다. 외부 서비스·폰트 다운로드·네트워크 연결을 사용하지 않습니다.

디자인 보드는 로컬에서 `python3 design/create-previews.py`로 다시 생성합니다. 이 명령에는 무료 SVG 렌더러인 `rsvg-convert`가 필요합니다. 미리보기 자체는 브라우저에서 바로 열 수 있습니다.

검증: SVG와 PNG 파싱 및 보드 렌더링 확인, 네 아이콘·세 디자인의 조합 변경, 서재·읽기 전환, 툴바 색상 변경·메뉴 전환, 예시 문서 열기 및 검색을 DOM 모델에서 확인했습니다. 보드 이미지는 직접 시각 검토했습니다. 실제 브라우저의 반응형 레이아웃 검사는 포함하지 않았습니다.
